Верни только JSON реестра утверждений.

Слои:
- fact: только то, что есть в факте, ссылка fact:*
- alfa: только пересказ карточки Альфа-Банка с датой, ссылка card:*
- model: вывод по признаку клиента или механизму, без атрибуции банку
- hypothesis: предположение, формулировка через «платёжная связь», без «поставщик» и «покупатель»

Не выдумывай числа. Каждое число ссылается на fact, card или calc.
Не утверждай тип ставки, сумму долга и валютную долю, если их нет в user_provided.
Сценарии без вероятностей: low, medium или high.
