Проверка 23 октября 2026. Секретов в репозитории нет: уровень логов берётся из `ALFA_LOG_LEVEL`.

## Источники

Включённые источники опрашиваются по расписанию из `pipelines/news/sources.yaml`. Резерв выключен, пока источник его группы не перейдёт в `degraded` или `down`. В интерфейсе `preview` отдаются заголовок, фрагмент до 400 символов и ссылка. Полный текст остаётся в sqlite для извлечения событий и не показывается целиком.

Правила сбора: только http и https, честный User-Agent `alfa-hackaton-news/1.0`, robots.txt, не больше одного запроса в секунду на домен, без обхода платного доступа и капчи, без исполнения JavaScript. Адрес от пользователя проверяется на SSRF после DNS и на каждом редиректе.

## Библиотеки

Версии новостного контура зафиксированы в `requirements-news.txt` (образ без torch) и в `requirements.txt`. CPU-сборка `torch==2.14.1+cpu` ставится с `https://download.pytorch.org/whl/cpu`: в `requirements.txt` для этого указан `--extra-index-url`.

| Пакет | Версия | Зачем |
| --- | --- | --- |
| feedparser | 6.0.14 | RSS и Atom |
| httpx | 0.28.1 | HTTP, пул соединений, таймауты. Редиректы обходятся в коде |
| trafilatura | 2.3.1 | основной извлекатель текста |
| readability-lxml | 0.8.1 | запасной извлекатель |
| lxml | 6.1.3 | разбор HTML, селекторы реестра и последняя очередь |
| pyyaml | 6.0.3 | `sources.yaml` и `config.yaml` |
| pydantic | 2.14.1 | схема `NewsDoc` |
| numpy | 2.5.4 | косинус смыслового дедупа |

Смысловой дедуп считает косинус. При `news.dedup.embedder: bge-m3` берётся `BAAI/bge-m3` через `sentence-transformers`, если пакет и веса модели уже есть. Если модели нет, запуск не падает: в отчёт пишется `hashing`, порог и окно остаются из конфига (`0.92`, 72 часа). Подбор порога экспериментами в этот модуль не входит. В отчёт каждого запуска попадают 8 случайных кластеров.

JavaScript-страницы помечаются `needs_js` и не ставятся в очередь извлечения. Сам парсер модель не вызывает.
